# 📌 Newsletter Sign-Up Form with Success Message

This project is a solution to the "Newsletter Sign-up Form with Success Message" challenge on Frontend Mentor.
The challenge focuses on building a responsive form with validation, submission handling, and a dynamic success state using DOM manipulation.


## 🖼️ Preview

![Project Preview](src/preview/preview.jpg)


## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a responsive sign-up form layout
- Implementing form validation for required fields and email format
- Handling form submission and displaying a success message with the entered email
- Managing UI state changes between form and success message views
- Applying hover and focus states to all interactive elements
- Reproducing the design as closely as possible based on the provided layout


## 🧠 What I Learned

Through this project, I practiced:

- Building form structures using semantic HTML
- Implementing client-side validation for user input
- Manipulating the DOM to handle dynamic UI states
- Managing success and error states within a form flow
- Improving responsive design for form-based components
- Enhancing user experience through feedback and interaction states

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/react-projects.git

# Navigate to the project directory
cd 40-newsletter-sign-up-with-success-message

# Install dependencies
npm install

# Start the development server
npm run dev
```

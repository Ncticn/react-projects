# 📌 Bento Grid

This project is a solution to a Bento Grid Layout challenge on Frontend Mentor.
The challenge focuses on building a responsive grid-based layout using CSS Grid, inspired by modern bento-style UI patterns.

## 🖼️ Preview

![Project Preview](src/preview/preview.jpg)

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a responsive bento-style grid layout
- Structuring the layout using CSS Grid techniques
- Ensuring the layout adapts correctly across different screen sizes
- Organizing content blocks to maintain visual balance and hierarchy
- Reproducing the design as closely as possible based on the provided layout

## 🧠 What I Learned

Through this project, I practiced:

- Building complex layouts using CSS Grid
- Structuring bento-style UI components in a clean and maintainable way
- Managing responsive behavior within grid-based layouts
- Improving layout planning and visual hierarchy
- Paying close attention to spacing and alignment in grid systems

## 🛠️ Tech Stack & Concepts

- **Framework / Library:** React

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/react-projects.git

# Navigate to the project directory
cd 30-bento-grid

# Install dependencies
npm install

# Start the development server
npm run dev
```

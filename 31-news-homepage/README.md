# 📌 News Homepage

This project is a solution to the "News Homepage" challenge on Frontend Mentor.  
The challenge focuses on building a responsive news homepage using modern layout techniques, with particular emphasis on CSS Grid and layout decision-making.

## 🖼️ Preview

![Project Preview](src/preview/preview.jpg)

---

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a responsive layout that adapts correctly across different screen sizes
- Building the page structure using CSS Grid for complex layout sections
- Applying hover and focus states to all interactive elements
- Reproducing the design as closely as possible based on the provided layout

---

## 🧠 What I Learned

Through this project, I practiced:

- Building complex page layouts using CSS Grid
- Making layout decisions for content-heavy interfaces
- Managing hover and focus states for better accessibility and usability
- Implementing a mobile hamburger menu for responsive navigation
- Improving responsive design strategies for multi-section pages
- Paying close attention to spacing, hierarchy, and visual balance

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/react-projects.git

# Navigate to the project directory
cd 29-tech-book-club-landing-page

# Install dependencies
npm install

# Start the development server
npm run dev
```

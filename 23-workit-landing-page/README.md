# 📌 Workit Landing Page

This project is a solution to the "Workit Landing Page" challenge on Frontend Mentor.  
The challenge focuses on building a fully responsive landing page using only HTML and CSS, with an emphasis on layout accuracy and visual details such as curved section borders.

## 🖼️ Preview

![Project Preview](src/preview/preview.jpg)

---

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a fully responsive layout that adapts smoothly to different screen sizes
- Structuring the UI using reusable React components
- Applying hover states to interactive elements to improve user feedback

---

## 🧠 What I Learned

Through this project, I practiced:

- Building responsive layouts with React and Tailwind CSS
- Organizing the UI into reusable and maintainable components
- Translating a static design into a component-based structure
- Implementing hover interactions using utility-first CSS
- Paying close attention to visual details, spacing, and consistency

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/react-projects.git

# Navigate to the project directory
cd 23-workit-landing-page

# Install dependencies
npm install

# Start the development server
npm run dev
```

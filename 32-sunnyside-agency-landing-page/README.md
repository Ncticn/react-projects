# 📌 Agency Landing Page

This project is a solution to the "Agency Landing Page" challenge on Frontend Mentor.  
The challenge focuses on building a responsive landing page using mainly HTML and CSS, with a small amount of JavaScript used for the mobile navigation toggle.

## 🖼️ Preview

![Project Preview](src/preview/preview.jpg)

---

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a responsive layout that adapts correctly across different screen sizes
- Building the layout using modern HTML and CSS layout techniques
- Implementing a mobile navigation toggle using TypeScript
- Applying hover states to all interactive elements
- Reproducing the design as closely as possible based on the provided layout

## 🧠 What I Learned

Through this project, I practiced:

- Building responsive layouts using HTML and CSS
- Implementing a mobile navigation menu using basic TypeScript
- Managing hover states to improve user interaction
- Improving layout structuring for landing page designs

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/react-projects.git

# Navigate to the project directory
cd 32-sunnyside-agency-landing-page

# Install dependencies
npm install

# Start the development server
npm run dev
```

# 📌 BMI Calculator

This project is a solution to the "Body Mass Index Calculator" challenge on Frontend Mentor.
The challenge focuses on building an interactive BMI calculator that allows users to calculate their body mass index based on metric or imperial units.

## 🖼️ Preview

![Project Preview](src/preview/preview.jpg)

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Creating a responsive BMI calculator layout
- Allowing users to switch between metric and imperial units
- Handling user input for height and weight values
- Calculating BMI based on selected unit system
- Displaying BMI result along with weight classification and healthy range
- Applying hover and focus states to all interactive elements
- Reproducing the design as closely as possible based on the provided layout

## 🧠 What I Learned

Through this project, I practiced:

- Building unit-based calculation logic (metric and imperial systems)

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/react-projects.git

# Navigate to the project directory
cd 51-bmi-calculator

# Install dependencies
npm install

# Start the development server
npm run dev
```

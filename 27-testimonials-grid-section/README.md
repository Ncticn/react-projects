# 📌 Testimonials Grid Section

This project is a solution to the "Testimonials Grid Section" challenge on Frontend Mentor.  
The challenge focuses on practicing CSS Grid by building a responsive testimonials layout that adapts smoothly across different screen sizes.

## 🖼️ Preview

![Project Preview](src/preview/preview.jpg)

---

## 🎯 Overview

During the development of this project, the following aspects were implemented:

- Building a layout structure using CSS Grid
- Ensuring the design adapts correctly across various screen sizes
- Matching the provided design as closely as possible

---

## 🧠 What I Learned

Through this project, I practiced:

- Building complex layouts using CSS Grid
- Managing responsive behavior within grid-based layouts
- Structuring content for consistency and readability
- Paying attention to spacing, alignment, and layout balance

## ⚙️ Installation & Running the Project

To run this project locally, follow these steps:

```bash
# Clone the repository
git clone https://github.com/Ncticn/react-projects.git

# Navigate to the project directory
cd 27-testimonials-grid-section

# Install dependencies
npm install

# Start the development server
npm run dev
```
